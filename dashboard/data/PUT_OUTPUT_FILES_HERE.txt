Only optional dashboard-specific files belong here.

Do not put backtest_predictions.parquet in place of future_forecasts.parquet.
The general future file must contain latest_observed_waiting_list and must not contain actual.
The optimisation future file must contain latest_observed_incomplete_decision_to_admit and forecast_target=incomplete_decision_to_admit.

- dashboard/data/nhs_trust_coordinates.csv
